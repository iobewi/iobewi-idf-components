# Rapports projet

Ce dossier regroupe les rapports de suivi projet,
principalement organisés par sprint ou jalon.

Objectifs :
- tracer l’avancement,
- documenter les décisions et résultats,
- conserver un historique lisible du projet.

## Contenu typique

- rapports de sprint
- bilans intermédiaires
- comptes rendus techniques

Ces documents sont factuels et datés.
Ils ne sont pas modifiés a posteriori.
