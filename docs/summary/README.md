# Synthèses

Ce dossier contient les documents de synthèse à date,
destinés à fournir une vue globale et rapide de l’état du projet.

Objectifs :
- donner une vision consolidée (technique et qualité),
- faciliter la communication transverse,
- servir de point d’entrée pour un audit ou une revue.

## Contenu typique

- résumés globaux
- états de conformité
- snapshots projet à une date donnée

Les documents de ce dossier peuvent être régénérés périodiquement.
