# Guides et bonnes pratiques

Ce dossier regroupe les guides techniques et documents de référence
utilisés au quotidien par les développeurs.

Objectifs :
- harmoniser les pratiques de développement,
- garantir la conformité aux conventions ESP-IDF,
- faciliter l’onboarding et la montée en compétence.

## Contenu typique

- conventions de codage et d’architecture des composants
- bonnes pratiques ESP-IDF (CMake, Kconfig, logs, mémoire)
- guides d’intégration (outils, IA, process internes)
- documents de cadrage fonctionnel (CDC)

Ces documents peuvent évoluer régulièrement mais doivent rester
**cohérents avec l’état du code**.
