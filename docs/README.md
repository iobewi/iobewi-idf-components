# Documentation – iobewi-idf-components

Ce dossier regroupe l’ensemble de la documentation technique, process et projet
associée aux composants ESP-IDF du dépôt **iobewi-idf-components**.

La documentation est organisée par finalité afin de faciliter :
- l’onboarding des développeurs,
- les revues d’architecture,
- les audits de conformité,
- le suivi projet (sprints, jalons).

## Structure

- `architecture/` : vues système, choix d’architecture, intégration micro-ROS
- `guides/` : guides techniques, conventions, bonnes pratiques
- `audits/` : audits de conformité, campagnes et plans qualité
- `reports/` : rapports de sprint et livrables projet
- `summary/` : synthèses et états globaux à date

Chaque sous-dossier contient un `README.md` décrivant son périmètre.
