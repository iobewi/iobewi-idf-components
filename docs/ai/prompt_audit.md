# 🔍 Prompt Audit / Refactor — iobewi-idf-components

Tu réalises un **audit de conformité** ou un **refactor**.

## Objectif

- identifier les violations du standard
- proposer une trajectoire de correction
- préserver la stabilité API si possible

## Méthode attendue

1. Identifier les violations :
   - taxonomie
   - structure
   - API
   - dépendances
2. Classer :
   - P0 : bloquant
   - P1 : important
   - P2 : amélioration
3. Proposer un plan d’action clair

## Interdictions

- ❌ refactor “créatif”
- ❌ renommage inutile
- ❌ changement d’API sans justification
- ❌ mélange correction / feature

## Livrable attendu

- constats factuels
- références au standard (`STD-*`)
- plan de correction étape par étape
