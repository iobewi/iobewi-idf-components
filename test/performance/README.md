# Tests de performance

Ce dossier regroupe les tests de performance (latence, heap, CPU) des composants.
Les seuils et conditions de mesure doivent être explicités dans chaque test.

## Règles

- Un test = un projet ESP-IDF autonome.
- Mesures répétables (conditions et outillage stables).
- Reporter les deltas par rapport aux dernières valeurs validées.

## Références

- Campagne de test : `test/CAMPAGNE_TEST.md`
- Reporting : `test/reporting/REPORT_TEMPLATE.md`
