# Tests d'intégration

Ce dossier regroupe les tests d'intégration combinant plusieurs composants.
Les tests doivent vérifier la cohérence des interfaces et la gestion
standardisée des erreurs.

## Règles

- Un test = un projet ESP-IDF autonome.
- Documenter les composants couplés et les scénarios exercés.
- Conserver les logs de build et d'exécution.

## Références

- Campagne de test : `test/CAMPAGNE_TEST.md`
- Reporting : `test/reporting/REPORT_TEMPLATE.md`
